# 🎬 Netflix Movies & TV Shows - Exploratory Data Analysis (EDA)

## 📖 Project Overview
This project performs Exploratory Data Analysis (EDA) on the Netflix Movies and TV Shows dataset using Python. The objective is to clean the dataset, explore the data, visualize trends, and generate meaningful insights.

## 🎯 Objectives
- Load and understand the dataset
- Clean missing values and duplicates
- Perform exploratory data analysis
- Visualize important trends
- Draw meaningful insights

## 📂 Dataset
- Dataset: Netflix Movies and TV Shows
- Source: Kaggle

## 🛠️ Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## 📋 Project Phases
- Phase 1: Data Loading & Understanding
- Phase 2: Data Cleaning & Preprocessing
- Phase 3: Data Visualization
- Phase 4: Advanced Exploratory Data Analysis
- Phase 5: Insights & Conclusion

## 📊 Key Insights
- Movies are more common than TV Shows.
- Netflix expanded rapidly after 2015.
- The United States has the highest number of titles.
- TV-MA is the most common content rating.
- Drama and International Movies are among the most popular genres.
